# Скриншоты для README

README ссылается на эти файлы — пересними их и положи сюда:

- `desktop.png` — рабочий стол с Waybar, парой окон и красивыми обоями (сейчас тут временный плейсхолдер)
- `rofi.png` — открытый launcher (`Super+Space`) или меню обоев (`Super+W`)
- `terminal.png` — Kitty с fastfetch-дашбордом и cava
- `lockscreen.png` — hyprlock (`Super+L`, снять можно вторым устройством или `grim` по таймеру: `sleep 3 && grim lockscreen.png` перед блокировкой не сработает — проще `hyprlock` на втором tty или фото)

Снять область: `Ctrl+Print`, весь экран: `Print` (сохраняется в ~/Pictures/).
